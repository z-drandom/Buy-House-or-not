# 买房 vs 租房 · 专业测算器

一个自包含的单文件网页工具：填写房产、贷款、租房与财务参数，程序逐月推演两条路径的完整现金流，并以 8 张联动图表 + 结论横幅 + 指标卡 + 逐年明细表直观呈现「买房还是租房更划算」。

## 使用方法

下载 `index.html`，用任意现代浏览器打开即可——无需安装、无需联网（ECharts 图表库已内嵌，约 1 MB）。修改任意参数后全部结果自动重算；页面自动适配系统的浅色/深色模式。

## 测算方法论

采用**同额现金流对照法**：让两条路径投入完全相同的现金，比较持有期末的净资产。

| | 买房路径 | 租房路径 |
|---|---|---|
| 期初 | 首付 + 契税 + 中介费 + 一次性费用 | 押金；其余同额资金投入年化收益率 r 的投资组合 |
| 逐月 | 月供 + 物业费 + 维修准备金 | 租金（按年增长）+ 定期换租成本；两路径月支出差额继续投入组合（差额为负则支取） |
| 期末 | 房产市值 − 卖出交易成本 − 剩余贷款本金 | 投资组合终值 + 押金退回 |

贷款引擎支持**纯商贷 / 纯公积金 / 组合贷**（公积金部分受额度上限约束，超出自动划入商贷）与**等额本息 / 等额本金**两种完整摊还表。

结论指标包括：盈亏平衡点（买房净资产追上租房路径的月份）、期末净资产差额、贷款总利息、静态租售比（售价÷年租金）、买房相对租房的隐含年化收益率（IRR，用于自洽性校验）。

## 模型假设与局限

- 房价、租金按年复利增长；物业费随通胀增长；维修费按当期房价固定比例计提。
- 投资组合可为负值，视为按同一利率融资的简化处理。
- 未纳入：房贷利息个税抵扣、房产税试点、提前还贷、装修支出、学区/落户等非货币收益。
- 结论对「房价年涨幅」与「投资收益率」两个假设最敏感——请务必结合图⑦⑧判断，本工具不构成投资建议。

## 开发

```bash
node tests/calc.test.js   # 计算引擎对照测试（等额本息/等额本金公式、组合贷拆分、IRR 自洽等 25 项）
node build.mjs            # 从 src/ 与 vendor/ 装配出自包含的 index.html
```

目录结构：

```
index.html               # 构建产物：自包含单文件（交付物）
src/calc.js              # 计算引擎（纯函数，node 可直接测试）
src/app.js               # 界面逻辑与 ECharts 图表
src/style.css            # 样式与浅色/深色设计令牌
src/index.template.html  # 页面骨架模板
vendor/echarts.min.js    # Apache ECharts 5.6.0（Apache-2.0 协议）
tests/calc.test.js       # 引擎对照测试
build.mjs                # 装配脚本
```
